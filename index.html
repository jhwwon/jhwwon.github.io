PROJECT DETAILS

FTP 클라이언트-서버 구현

주요 기술

C Linux

주요 기능

  • 파일 전송 - get/put 명령어를 통한 서버-클라이언트 간 파일 업로드/다운로드
  • 디렉토리 관리 - ls/cd 명령어로 서버 디렉토리 탐색 및 이동
  • 로컬 명령어 - cls/ccd 명령어로 클라이언트 로컬 디렉토리 관리
  • 멀티클라이언트 지원 - pthread와 select()를 활용한 동시 다중 클라이언트 연결 처리
  • 대용량 파일 처리 - 65KB 청크 단위로 분할하여 안정적인 파일 전송

핵심 구현

  • 멀티스레딩 아키텍처 - pthread를 사용하여 각 클라이언트별 독립적인 스레드 생성으로 동시성 확보
  • I/O 멀티플렉싱 - select() 시스템 콜을 활용한 효율적인 소켓 이벤트 처리
  • 파일 청킹 시스템 - 대용량 파일을 BUFSIZE(65535) 단위로 분할하여 메모리 효율성과 전송 안정성 확보
  • 프로토콜 설계 - 클라이언트-서버 간 명령어 기반 통신 프로토콜 구현
  • 표준 출력 리다이렉션 - switchStdout()/revertStdout() 함수로 명령어 실행 결과를 파일로 캡처

트러블슈팅

문제 멀티클라이언트 동시 접속 문제
해결 초기 단일 클라이언트 서버에서 pthread 도입으로 동시 다중 연결 처리 가능
문제 대용량 파일 전송 중단 문제
해결 네트워크 불안정 시 전송 실패를 방지하기 위해 파일을 65KB 청크 단위로 분할 전송하여 안정성 확보

결과 및 회고

FTP 클라이언트와 서버간의 통신을 통해 소켓 프로그래밍의 기초와 파일 전송 설계 단계를 구현함으로써 통신의 기본적인 개념을 학습할 수 있었습니다.
