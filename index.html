PROJECT DETAILS

FTP 클라이언트-서버 구현

주요 기술

C Linux

주요 기능

  • 파일 전송 - get/put 명령어를 통한 서버-클라이언트 간 파일 업로드/다운로드
  • 디렉토리 관리 - ls/cd 명령어로 서버 디렉토리 탐색 및 이동
  • 로컬 명령어 - cls/ccd 명령어로 클라이언트 로컬 디렉토리 관리
  • 멀티클라이언트 지원 - pthread와 select()를 활용한 동시 다중 클라이언트 연결 처리
  • 대용량 파일 처리 - 65KB 청크 단위로 분할하여 안정적인 파일 전송

핵심 구현

  • 멀티스레딩 아키텍처 - pthread를 사용하여 각 클라이언트별 독립적인 스레드 생성으로 동시성 확보
  • I/O 멀티플렉싱 - select() 시스템 콜을 활용한 효율적인 소켓 이벤트 처리
  • 파일 청킹 시스템 - 대용량 파일을 BUFSIZE(65535) 단위로 분할하여 메모리 효율성과 전송 안정성 확보
  • 프로토콜 설계 - 클라이언트-서버 간 명령어 기반 통신 프로토콜 구현
  • 표준 출력 리다이렉션 - switchStdout()/revertStdout() 함수로 명령어 실행 결과를 파일로 캡처

트러블슈팅

문제 멀티클라이언트 동시 접속 문제
해결 초기 단일 클라이언트 서버에서 pthread 도입으로 동시 다중 연결 처리 가능
문제 대용량 파일 전송 중단 문제
해결 네트워크 불안정 시 전송 실패를 방지하기 위해 파일을 65KB 청크 단위로 분할 전송하여 안정성 확보

결과 및 회고

FTP 클라이언트와 서버간의 통신을 통해 소켓 프로그래밍의 기초와 파일 전송 설계 단계를 구현함으로써 통신의 기본적인 개념을 학습할 수 있었습니다.

이커머스 고객 이탈 예측

Kaggle Dataset

E-commerce Customer Behavior Dataset

주요 기술

Python Scikit-learn

주요 기능

  • 이탈 확률 실시간 예측 - 15개 핵심 특성 기반 4단계 위험도 분류 (낮음/보통/높음/매우 높음)
  • 4개 모델 성능 비교 - Logistic Regression, Decision Tree, Random Forest, XGBoost 평가
  • Feature Importance 시각화 - 고객 서비스 통화 수, 평생 가치, 장바구니 이탈률 등 주요 지표 분석

  • 특성 선택 - Random Forest 기반 특성 중요도 분석으로 24개→15개 특성 선택 (누적 중요도 86% 유지)
  • 클래스 불균형 해결 - SMOTE로 클래스 불균형 해결 (29:71 → 50:50), Recall 32.7%p 향상

  • 모델 선정 - 5개 모델 비교 후 XGBoost 선정 (ROC-AUC 98.23%)
  • 웹앱 구현 - Streamlit 웹앱 구현 - 모델 캐싱, 세션 상태 관리, Plotly 인터랙티브 차트

결과 및 회고

PROJECT DETAILS

AI 기반 주조 결함 검사 시스템

Kaggle Dataset

Real-life Industrial Dataset of Casting Product

주요 기술

Python PyTorch

주요 기능

  • 고성능 결함 탐지 - EfficientNet-B0 기반 99.86% 정확도 (손실률 0.006, 모델 크기 16.3MB)
  • AI 분석 리포트 - Claude Sonnet 4.5가 전문가 수준의 결함 분석 및 조치 제안
  • Grad-CAM 시각화 - AI 판단 근거를 히트맵으로 명확히 제시
  • PDF 보고서 자동 생성 - 한글 지원, 전문 검사 양식 (ReportLab 기반)
  • 실시간 통계 대시보드 - 일일/주간/월간 검사 통계 및 추이 분석 (Plotly 인터랙티브 차트)

핵심 구현

  • EfficientNet-B0 전이학습 - ImageNet 사전학습 가중치 활용, 손실률 0.006 달성으로 안정적 일반화 성능 확보
  • LLM 통합 아키텍처 - Anthropic API 클라이언트 구현 및 구조화된 프롬프트 빌더로 일관된 분석 품질 보장
  • 검사 오케스트레이터 패턴 - CNN 추론 → Grad-CAM → LLM 분석 → PDF 생성 파이프라인 구현
  • 검사 이력 관리 - JSON 기반 영구 저장소 및 기간별 필터링 (오늘/7일/30일) 통계 집계
  • 모듈형 아키텍처 - classifiers, explainers, llm, services, utils로 관심사 분리 설계

결과 및 회고

EfficientNet-B0 전이학습으로 99.86% 정확도를 달성하고 Claude Sonnet 4.5 LLM을 통합하여 전문가 수준의 분석 리포트를 자동 생성함으로써, 단순 딥러닝 분류를 넘어 Grad-CAM과 LLM을 결합한 설명 가능하고 실무 적용 가능한 AI 시스템을 구축한 경험을 얻었습니다.
